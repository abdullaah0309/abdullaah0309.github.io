TITAN-SPARSE: 2:4 Structured Sparse Tensor Core NPU

Data movement from SRAM and DRAM consumes over 80% of total chip energy in modern deep learning accelerators. TITAN-SPARSE solves this memory bandwidth bottleneck by implementing NVIDIA Ampere/Hopper-style 2:4 structured sparsity. For every block of 4 weights, memory transmits only the 2 non-zero weights and a 4-bit metadata tag, cutting raw SRAM read bandwidth by 50% while doubling compute density.

32-Bit Workload-Adaptive ALU with Full ASIC GDSII Silicon Layout

A low-power dual-mode processor arithmetic execution core designed for edge mobile SoCs. Combines dynamic 16-bit operand isolation to cut transistor switching activity on small integers with a 4-lane INT8 SIMD vector dot-product engine and hardware ReLU.

  • Dynamic Operand Isolation: Architectural zero/sign detection gates upper 16-bit combinational logic paths whenever inputs fit in 16 bits, slashing dynamic switching power by up to 50%.
  • Full-Custom GDSII Silicon Layout: Generated in KLayout 0.30.12 featuring a 400μm × 400μm die boundary, 108 peripheral bond pads, dual concentric VDD/VSS power rings (Metal 4 & 5), and standard cell macro partitions.
  • FPGA Physical Verification: Placed and routed on AMD Artix-7 silicon with 107 mW total power (36 mW dynamic), 689 Slice LUTs, and zero failing endpoints at 100 MHz.

2D Weight-Stationary Systolic Array Mesh Core

A 2D spatial systolic matrix multiplication core based on Google TPU architecture. Activations stream horizontally while partial sums propagate vertically across a grid of Processing Elements (PEs) featuring time-skewing pipeline alignment registers.

  • Spatial Wavefront Pipelining: Integrated D-flip-flop skewing registers ensure proper alignment between horizontal activation wavefronts and vertical partial sums.
  • Clean Silicon Placement: Tightly packed in clock region X0Y0 on Artix-7 silicon, achieving 102 mW total power (32 mW dynamic) with minimal routing parasitic overhead.
